# 🚀 ErrandGo Backend

**ErrandGo** is a backend application built using **Spring Boot** that allows users to register as clients or errand runners ("errand boys"). It supports user registration, errand assignments, and admin-level reporting features including Excel report export.

---

## 🛠️ Tech Stack

- Java 17+
- Spring Boot
- MySQL
- JPA (Hibernate)
- Maven
- Docker
- REST API
- Excel Export (Apache POI or similar)
